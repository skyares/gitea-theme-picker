📖 使用说明 & 开发定制

🚀 快速开始

  1. 点击 📄 选择 CSS 文件 选一批 .css 主题文件
  2. 或点 📁 选择文件夹 一次性加载整个目录（推荐，能保留目录结构）
  3. 或直接把文件/文件夹 拖拽 到页面上
  4. 加载后，右上角的 下拉框 会按系列分组显示所有主题
  5. 选择任意主题，预览区立即应用
  6. 点 🗑 清空 移除所有已加载的主题

💡 使用技巧

场景做法
一次加载整套主题用「选择文件夹」，一次性把 theme-* 全部拖入

区分同名文件通过文件夹上传/拖拽文件夹，下拉里会显示带目录的完整路径

📛 文件名识别规则

本工具按文件名自动分组、显示中文名，格式如下：

theme-<系列>-<风味>-<色调>[-auto].css
段示例说明
前缀theme-固定，缺了也能加载但会归入「其他」
系列github-catppuccin决定归到哪个大分组
风味latte/frappe/mocha部分系列会按风味再分子组
色调mauve/blue/green会映射成中文显示
后缀-auto表示跟随系统，显示为「自动」

示例：

theme-catppuccin-mocha-mauve.css   → 🎨 Catppuccin / 🌑 Mocha / 淡紫
theme-github-high-contrast-dark.css → 🐙 GitHub · 高对比 / 深色
theme-auto.css                      → 🏠 Gitea 基础 / 自动

📁 目录结构建议

推荐按系列放到不同子目录，这样可以避免同名冲突：

themes/
├── catppuccin/
│   ├── theme-catppuccin-mocha-mauve.css
│   └── theme-catppuccin-latte-blue.css
├── github/
│   ├── theme-github-dark.css
│   └── theme-github-light.css
└── theme-auto.css

🛠 开发定制

如果你想自己改代码，下面是最常调整的 6 个地方。它们都在 <script> 顶部，全局搜索对应变量名就能找到。

① 新增一个「系列」THEME_SERIES

比如想让所有 theme-vscode-* 归到「💻 VS Code」：

const THEME_SERIES = [
  // ★ 新增这一行，注意前缀以 - 结尾
  { prefix:'theme-vscode-', name:'vscode', label:'💻 VS Code', order:240 },
  // ...其他不变
];

order 决定分组在下拉框中的顺序，越小越靠上。参考值：

  • 30 — 基础主题组（Gitea 基础）
  • 100–199 — GitHub 变体系列
  • 200–299 — Catppuccin / Tokyo Night 等
  • 900 — 兜底「其他」
② 让某系列按「风味」再分组splitByFlavor

例如 Catppuccin 有 Latte/Frappé/Macchiato/Mocha 四种风味，代码里是：

{ prefix:'theme-catppuccin-', name:'catppuccin',
  label:'🎨 Catppuccin', splitByFlavor:true, order:200 }

开启后，会从 rest 里剥离 latte 等关键词，把组拆成「🎨 Catppuccin · ☀️ Latte（浅色）」这种形式。

新增风味在 FLAVORS 里加：

const FLAVORS = {
  // ...
  espresso: { group:'espresso', label:'☕ Espresso', order:45 },
};
③ 新增色调的中文名TINT_KEYWORDS

现在 cyan 会原样显示。想让它显示为「青蓝」：

const TINT_KEYWORDS = {
  // ...
  cyan: '青蓝',
  teal: '青绿',  // 覆盖已有映射也行
};

复合词要放长键优先（代码已自动按长度排序）：

'high-contrast':'高对比',    // 会先匹配整段
'high':'高', 'contrast':'对比',  // 分散写也能兜底
④ 基础主题 / 其他分组的判断BASIC_MODES

「🏠 Gitea 基础」组里目前是 theme-auto.css、theme-dark.css、theme-light.css 这种纯模式文件。

如果还有 theme-system.css，加进去：

const BASIC_MODES = new Set(['auto', 'dark', 'light', 'system']);

改分组名：

const BASIC_GROUP = {
  group:'basic',
  groupLabel:'🏠 纯模式主题',
  order:30
};
⑤ 调整预览区自身的颜色回退变量

预览页本身也是一套 :root 变量（未加载主题时兜底）。搜索 :root 找到最上面那块，比如：

:root{
  --color-body:#1e1e2e;         /* 页面背景 */
  --color-text:#cdd6f4;         /* 主要文字 */
  --color-primary:#cba6f7;      /* 主色（链接、按钮） */
  --color-navbar: var(--color-nav-bg, #181825);  /* 工具条背景 */
  /* ... */
}

想换成自己的默认配色，直接改这几行即可。加载主题后这些会被主题覆盖。

⑥ 改工具条按钮顺序 / 文案HTML

搜索 <div class="toolbar"> 找到工具条，里面的按钮随你调整：

<button class="btn btn-primary" id="btn-files">📄 选择 CSS 文件</button>
<button class="btn" id="btn-folder">📁 选择文件夹</button>
<button class="btn btn-danger" id="btn-clear">🗑 清空</button>

改文案直接改标签里的文字；改样式改 class（可选 btn/btn-primary/btn-danger）。

🔍 关键函数速查

函数作用
describe(fileKey)把文件名解析成 { 分组、中文名、色调 } 等元信息
splitTint(raw)把 high-contrast-colorblind-dark 拆成 高对比·色盲·深色
getFileKey(file)返回 webkitRelativePath || name，用于唯一标识
ingestFiles(fileList)批量加载文件，写入 registry / themes
renderPicker()重建下拉框（按 order 排序分组）
applyTheme(id)把选中的主题应用到 #theme-link
resolveImports(text, key)处理 @import，同目录优先
renderScale()渲染主色阶 + 变量速览表

⚠ 已知限制

  • 单文件上传无法区分同名：浏览器只给 file.name，两个 theme-dark.css 会互相覆盖。→ 用文件夹上传/拖拽。
  • @import 依赖需一起加载：Auto 主题引用的 Latte/Mocha 文件如果没加载，会回退到「按原样加载」。
  • 不支持远程 URL：出于 CORS 考虑，主题必须是本地文件。

🎨 关于 CSS 变量名

本预览器使用 Gitea 官方变量名，其中 --color-nav-bg 是导航栏背景的标准名。旧主题若只定义 --color-navbar，本工具已做了兼容回退：

--color-navbar: var(--color-nav-bg, #181825);

主色阶 / Primary Scale

Catppuccin / GitHub 等主题的「色调变体」（红、粉、蓝、绿…）共用同一套基础色，只把整套 --color-primary-* 派生变量替换成对应颜色。下面这一整条色阶就是切换主题时真正变化的部分。

主色本体 · --color-primary
亮色系 · light-1 → light-7（数字越大越亮）
暗色系 · dark-1 → dark-7（数字越大越暗）
透明层 · alpha-10 → alpha-90（叠在白色背景上）
